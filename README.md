# 旅遊行程規劃（Trip Planner）

一頁式（Single Page）行動裝置行程規劃工具，純 HTML / CSS / 原生 JavaScript 打造，無需安裝任何套件或框架，下載即可在瀏覽器開啟使用。

## 功能

- **行程頁**：依 Day 1 ~ Day 4 分頁檢視行程，每張景點卡片包含時間、名稱、地址、簡介、推薦項目、建議停留時間、營業時間，並提供「開啟導航」按鈕（依地址自動產生 Google Maps 連結）
- **拖曳排序**：卡片可用滑鼠或手指拖曳調整順序（Pointer Events，桌機／手機皆適用）
- **手動新增景點**：輸入景點名稱與地址（可貼 Google Maps 連結）即可加入當日行程
- **影片選點**：可貼上 Instagram／YouTube 影片連結直接內嵌播放，並可將影片中提及的景點一鍵加入行程
- **當日天氣預報**：左側逐時預報、右側當日最高∕最低溫與降雨機率（目前為示範假資料）
- **底部導覽列**：行程／資訊／清單三大分頁
  - 資訊：航班、住宿、預約店家
  - 清單：待辦清單／購物清單，可新增、勾選完成、刪除
- **本機儲存**：使用瀏覽器 LocalStorage，關閉分頁後行程與清單資料不會遺失

## 如何使用

直接用瀏覽器開啟 `index.html` 即可（建議用手機瀏覽器開啟以獲得最佳體驗），或部署到任何靜態網頁空間（GitHub Pages、Netlify、公司內部網頁伺服器等）。

> ⚠️ 注意：此專案使用瀏覽器 LocalStorage 儲存資料，僅在「直接開啟本檔案」或「部署在正式網站環境」時才會正常運作並持久保存；在部分沙盒／預覽環境（例如聊天工具內建的即時預覽視窗）中，重新整理後資料可能不會保留。

## 技術

- 純原生 HTML / CSS / JavaScript，無外部框架依賴
- 字型使用 Google Fonts（Inter + Noto Sans TC）
- 拖曳排序使用 Pointer Events API
- 響應式設計，行動裝置優先（max-width 480px 置中版面）
